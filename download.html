  • Full public dataset open_release.jsonl · 11,176 questions over 525 maps · 12.1 MB
  • Leaderboard evaluation set eval_500.jsonl · 499 questions over 310 maps · 547 KB
  • README Schema, taxonomies, image sources, and usage notes · also as Markdown

Notes

The evaluation set is the fixed sample of questions on which every leaderboard entry is scored and is a subset of the full public dataset.

A private test set of roughly a quarter of the maps is held back and is not part of either file.

Answers are short free text, not multiple choice. An LLM judge should be used.
